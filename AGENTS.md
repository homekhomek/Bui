Read README.md before doing any work on this project. It holds the project rules (data.js for numbers/game data, translate.js for player-facing strings, centered layout, Saccharide palette only, Waloh body font, Marker2 heading font, text sizes base and up only). Keep README.md high-level only.

Always have the dev server running while working: if `npm run dev` is not already running, start it in the background before making changes, and tell the developer the local URL so they can watch changes live.
